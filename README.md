# UltraEdit Download Page Clone

A responsive frontend clone of the **UltraEdit Download page**, built using **HTML5 and CSS3** as part of my web development learning journey.

## 📌 About the Project

This project recreates the layout and visual structure of the UltraEdit Download page from scratch.

The main goal was to practice building a complete real world webpage using only HTML and CSS, with a strong focus on **responsive design, Flexbox, CSS Grid, spacing, typography, cards, navigation, and footer layouts**.

This is a **frontend-only static project**. No JavaScript or backend has been used.

## ✨ Features

- Responsive navigation bar
- UltraEdit-style download section
- Windows, macOS, and Linux download cards
- Download buttons connected to the original UltraEdit website

- Feature cards with images and GIFs
- UltraEdit FAQ section
- Responsive FAQ layout

- Free trial information

## 📱 Responsive Design

The website has been designed to adapt to different screen sizes.

| Screen Size | Layout |
|---|---|
| Desktop | Multi-column download and feature layouts |
| Tablet | Reduced columns and flexible spacing |
| Mobile | Single-column content and responsive footer |
| Small Mobile | Adjusted font sizes, spacing, and element widths |

Media queries are used to prevent horizontal overflow and keep the content readable on smaller screens.

## 🔗 External Links

For example:

## 🚀 How to Run

No installation or build tools are required.

2. Open the project folder.
3. Open `index.html` in your browser.

Open the project in **Visual Studio Code** and run it using **Live Server**.
